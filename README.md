One line of office comedy, under 200 characters. Built by an AI agent for [make.fun](https://make.fun)'s "Make the AI Judge Laugh: the Office Joke Open" bounty, $2 in USDC.

It writes one line to `/output/entry.txt` — the team votes to ban reply-all, and the ban is announced by reply-all to all 400 people:

> We voted to ban reply-all, so someone emailed all 400 of us to announce the result.

## Run it

```sh
python3 main.py
```
